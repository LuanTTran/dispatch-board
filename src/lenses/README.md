# lenses

Presentational UI for each workspace region. Props in, events out. No OSDK calls here. Panels and hooks own the data.

**`activity/`** — Dispatch audit feed in the footer strip and full log dialog.

**`compare/`** — Side by side technician compare with green, yellow, and red parts path badges.

**`operations/`** — Focused work order job card and investigative expander (site, equipment, predictions, hub stock, prior decisions).

**`queue/`** — SLA sorted open work order list with urgency styling.
